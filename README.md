## 📂 Project Showcase

### 🛒 ApexSound — Full-Stack E-Commerce Platform

A complete e-commerce web application built with a multi-role system (**User, Vendor, Admin**), supporting product management, secure checkout, and order tracking.

**Tech Stack:**
`ASP.NET Core` `PostgreSQL` `React` `JWT Authentication` `Stripe` `Docker` `GitHub Actions CI/CD`

**Live Demo:** [apexsound.vercel.app](https://apexsound.vercel.app/)
**GitHub Repo:** [View Source Code](https://github.com/Majidkhan94/PROJECTS/tree/main/ApexSound)

**Key Features:**
- 🔐 Secure authentication & authorization using JWT (Login/Signup)
- 👥 Multi-role system — **User, Vendor, and Admin** dashboards
- 🛍️ Product listing with categories & search
- 🛒 Shopping cart system
- 💳 Checkout with **Stripe** payment integration and **Cash on Delivery (COD)** option
- 🧑‍💼 Admin/Vendor panel — add, edit, and delete products
- 📦 Order history and order tracking
- 🐳 Fully containerized with **Docker**
- 🔄 Automated CI/CD pipeline using **GitHub Actions**
